# Financial Loan Portfolio & Risk Analytics

An end-to-end data analytics project analyzing **financial loan applications, funded amounts, repayment status, and borrower risk profiles** using **Power BI** and data transformation workflows.

---

## Project Overview

This project transforms raw lending records into a clean, structured analytical dataset to evaluate portfolio health across loan statuses (**Fully Paid**, **Current**, and **Charged Off**). By segmenting performing loans from non-performing loans and analyzing borrower attributes (Debt-to-Income ratio, annual income, loan grade, employment length, and loan purpose), the dashboard highlights key drivers of loan defaults and interest yield.

---

## Repository Contents

| File | Description |
| :--- | :--- |
| `financial_loan.csv` | Raw financial loan dataset |
| `cleaned_financial_loan.csv` | Cleaned and standardized loan dataset ready for BI reporting |
| `Finance Loan Dashboard.pbix` | Multi-page interactive Power BI dashboard tracking loan KPIs, borrower demographics, and default risk |

---

## Key Metrics & Analysis

- **Portfolio KPIs:** Total Loan Applications, Total Funded Amount, Total Amount Received, Average Interest Rate, and Average Debt-to-Income (DTI) Ratio.
- **Good Loan vs. Bad Loan Segmentation:** Comparison of performing loans (`Fully Paid` + `Current`) against non-performing loans (`Charged Off`) by application volume, funded capital, and recovery rate.
- **Borrower & Regional Trends:** Monthly origination trends, state-level lending distribution, term length breakdown (36 vs. 60 months), and home ownership risk analysis.

---

## How to Use

1. **Inspect the Datasets:** Compare `financial_loan.csv` and `cleaned_financial_loan.csv` to review the standardized schema and cleaned fields.
2. **Explore the Dashboard:** Download `Finance Loan Dashboard.pbix` and open it in **Power BI Desktop** to interact with the KPI cards, slicers, and drill-down visuals.
